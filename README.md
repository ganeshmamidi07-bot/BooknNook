# 📚 BookNook – Books & Stationery

**Free Web Development Internship Online Task · Books & Stationery E-Commerce Project**

## 📖 Project Overview

BookNook is a modern, responsive e-commerce website for books and stationery products. Users can browse books, explore stationery, search products, add items to a shopping cart, and interact with login and registration pages.

## 🚀 How to Run

1. Download or extract the BookNook project.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your browser.

No server or database installation is required.

## 🛒 Shopping Cart

The shopping cart uses browser **LocalStorage** to save products.

Users can:

- Add products to cart
- View cart items
- Remove products
- See the total price
- Complete the demo checkout

## 👤 Login & Registration

The login and registration pages are currently **demo functionality**.

No real user accounts or passwords are stored.
